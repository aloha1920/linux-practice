# Kubernetes practice

The learner reports hands-on Minikube exercises with:
- Pods and Deployments
- ConfigMaps and Secrets
- ClusterIP, NodePort and LoadBalancer Services
- NGINX Ingress
- PersistentVolumes, PersistentVolumeClaims and StorageClass

Start with [INVENTORY.md](INVENTORY.md) for the reported resource names and evidence notes. Topic folders contain documentation placeholders until the actual tested YAML manifests are added.

**Security:** use dummy data in examples. Never commit real Secret values, decoded Secret data, credentials or kubeconfig files.
