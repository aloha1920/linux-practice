# Roadmap / Drafitra fianarana

**Status key / Fanalahidin'ny sata**
- **Practiced / Nampiharina:** learner reports completing hands-on exercises.
- **Strengthen / Hamafisina:** fundamentals exist but need repetition and deeper evidence.
- **Planned / Kasaina:** not yet completed; do not present as a finished skill or project.

## 1. Linux & Ubuntu — Strengthen / Hamafisina
- [x] Ubuntu on WSL2 and terminal practice (reported)
- [x] Basic file handling and Nano editing (reported)
- [ ] File permissions, ownership, users and groups
- [ ] Processes, services, package management and shell scripting
- [ ] Networking and log inspection

## 2. Git & GitHub — Strengthen / Hamafisina
- [x] Basic status, add, commit, push, pull, log and diff commands (repository notes)
- [ ] Branch creation and switching
- [ ] Merge conflicts and rebasing
- [ ] Pull requests, reviews and collaboration
- [ ] Clean commit history and documented workflow

## 3. Docker — Strengthen / Hamafisina
- [x] Docker Desktop, Engine, WSL integration and contexts (reported)
- [ ] Build images with Dockerfiles
- [ ] Run multi-container applications with Docker Compose
- [ ] Networks, volumes and persistent data
- [ ] Image tags, registries, scanning and cleanup

## 4. Kubernetes — Fundamentals practiced; advanced topics planned
- [x] Pods and Deployments
- [x] ConfigMaps and Secrets
- [x] ClusterIP, NodePort and LoadBalancer Services
- [x] NGINX Ingress exercise

- [ ] Namespaces and resource quotas
- [ ] Requests, limits, probes and autoscaling
- [ ] StatefulSets and DaemonSets
- [ ] Helm
- [ ] RBAC and service accounts
- [ ] Jobs and CronJobs
- [ ] Troubleshooting, security and cluster operations

- [ ] Terraform fundamentals

## 7. Monitoring & Logging — Planned / Kasaina
- [ ] Prometheus metrics

## 8. Cloud — Planned / Kasaina
- [ ] Cloud concepts: compute, networking, storage and IAM
- [ ] Learn deployment patterns using local/free learning resources first
- [ ] Compare cloud providers and understand cost/security basics
- [ ] First cloud deployment when ready; an AWS account is not required to begin studying

## Evidence rule / Fitsipika momba ny porofo
For every completed exercise, keep the manifest or source file, commands used, expected result, actual test output and date. Never commit passwords, tokens, kubeconfig files or real Secret values. A checklist item should be marked complete only after the exercise is repeated and evidence is saved.
