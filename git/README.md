# Git & GitHub

The repository already contains basic Git notes in [git-notes.txt](../git-notes.txt).

Commands recorded so far:
- `git status` — inspect working tree
- `git add` — stage changes
- `git commit` — save a local snapshot
- `git push` — publish commits
- `git pull` — fetch and integrate remote updates
- `git log --oneline` — compact history
- `git diff` — inspect unstaged changes
